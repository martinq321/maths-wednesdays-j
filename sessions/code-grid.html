Grown-up notes & next ideas

Start with predicting one move, then two. Let Jamie be the robot on a floor grid before trying it here. A turn changes where he faces; it does not move him.

Ask: “Which commands repeat? Where does the repeat start and finish? Can you make the same journey with less code?” A successful first session can be just missions 1–3.

Extensions: draw initials; make a delivery route; invent a maze for you to solve; change a square into a rectangle; compare two programs that trace the same path. Try rhythm loops with claps and taps away from the screen.
